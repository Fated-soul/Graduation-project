# 固定数据版本

DANDI 000718 的标题为“Offline ensemble co-reactivation links memories across days”。平台使用固定发布版本 0.260825.1902，对应 DOI 为 10.48324/dandi.000718/0.260825.1902。固定版本用于保证不同电脑、不同分析时间读取的是同一批公开文件，避免草稿版本更新后产生无法解释的结果差异。

# 数据规模与许可

该固定版本包含 2 只实验动物、20 个公开文件，总规模约 40.6 GB，采用 CC BY 4.0 许可并开放访问。仓库只保存目录、远程资源标识和分析摘要，不把完整数据集复制进 Git。报告或导出结果应同时记录 Dandiset 编号、固定版本、会话编号和原始资源地址。

# 数据标准与研究对象

数据采用 Neurodata Without Borders（NWB）标准，研究对象为小鼠，主要记录海马结构相关的单光子细胞群成像。DANDI 页面列出的数据集级模态不能代替会话级检查；某个会话是否包含视频、钙活动、脑电、肌电或睡眠标签，必须以该会话实际 NWB 内容和资源清单为准。

# 可复现性要求

同步目录只建立数据来源、实验动物、会话和远程文件之间的关系，不表示文件已经载入。Agent 回答时应区分“公开目录中存在该资源”“本地已经成功解析该资源”和“当前问题实际使用了该资源”。远程文件读取失败、缓存不完整或版本不一致时，应标记为数据可用性问题，不能用其他会话的数据补齐。
