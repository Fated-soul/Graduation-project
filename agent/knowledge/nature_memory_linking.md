# 研究结论

该研究讨论强烈厌恶经历如何与数日前形成的中性记忆发生回溯性关联。研究观察到，强烈厌恶经历之后的离线阶段，不仅与近期厌恶记忆相关的神经元集群会重新活动，过去中性记忆相关集群也可能被共同招募。论文将离线神经元集群共同再激活作为跨日记忆整合的一种可能机制。

# 行为证据

记忆关联的行为证据来自不同环境中的冻结表现比较。中性环境和新异环境本身没有施加足底电击，因此回忆阶段出现的冻结需要结合动物此前经历、环境类别和对照条件解释。不能只凭单个冻结片段认定记忆关联，应比较会话级冻结水平、不同环境和实验组条件。

# 离线活动

离线记录用于研究学习后的神经活动。论文报告，神经元集群共同活动与记忆整合存在关联，并指出相关集群活动可出现在清醒或睡眠等不同状态。脑电、肌电和睡眠标签应首先用于判定当时状态，再与同一离线会话内的钙活动共同解释。

# 结论边界

论文中的群体统计结论不能直接替代对单只动物的判断。平台可以用论文解释某种观察为什么值得关注，但不能把单只动物的短时变化直接表述为论文机制已经得到证明。Agent 应区分“当前动物的观测”“数据集中已有标签”和“论文中的总体研究结论”。
