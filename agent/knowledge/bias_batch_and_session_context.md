# 会话背景变量

同一动物在不同日期、时段、房间或设备上采集的数据可能受到适应程度、昼夜节律、操作人员和设备状态影响。平台按真实采集时间排列会话，是为了暴露这些背景差异，而不是把时间接近自动解释为生物学连续过程。

# 批次效应

不同批次的动物、试剂、装置设置、软件版本和分析参数都可能形成系统性差异。比较会话前应检查批次信息和采集条件；如果变化与实验组完全重合，就难以区分处理效应与批次效应。

# 排除与异常处理

排除标准应尽量预先确定，并记录每次排除的原因。信号质量差、文件损坏和动物状态异常可以构成排除依据，但不能只因结果不符合预期而删除记录。平台应保留原始状态和处理日志，让人工修订可审计。

# 重复与推广

单只动物、单次会话或单个批次的结果适合形成个案证据，不足以证明结论可推广。重复测量有助于观察稳定性，但应区分技术重复、时间重复和独立生物学重复。Agent 应明确当前结论基于哪个层级的证据。

# Agent 使用边界

Agent 在跨会话总结时应列出采集日期、研究阶段、可用模态和重要条件差异。当批次、时段或设备信息缺失时，应提示潜在混杂，不应将所有变化都归因于造模处理。
