# 分期依据

啮齿动物睡眠分期通常联合 EEG 频谱、EMG 张力和活动信息，把连续记录划分为清醒、NREM、REM 或未判定时间窗。自动模型输出的是依据训练规则得到的分类标签，不能脱离原始波形和会话条件作为绝对真值。

# 人工一致性

人工评分本身可能存在观察者差异。可靠评估应明确时间窗长度、评分规则和复核人员，并关注不同评分者一致的区间。边界时间窗、短暂觉醒、运动伪迹和信号掉线应优先进入人工复核，而不是被强制归入最近状态。

# 信号组合

清醒通常伴随较高肌电或明显活动；NREM 常见低肌电和较强慢波；REM 常表现为低肌电并伴随相对突出的 theta 活动。上述关系需要结合数据集采用的具体频段和阈值解释，不同实验装置、物种、记录部位和预处理方式之间不能直接复制阈值。

# 质量指标

平台应展示各状态持续比例、转移次数、未判定比例、信号缺失比例和人工修订记录。整体准确率可能掩盖少数状态识别不足，因此评估自动评分时还应关注各状态的精确率、召回率或混淆情况。

# Agent 使用边界

Agent 可以比较同一离线会话内不同睡眠状态下的神经活动，也可以描述跨会话的状态比例变化。若 EEG、EMG 与标签不在同一时间范围，或未判定比例较高，应停止逐时间窗解释并指出证据不足。
