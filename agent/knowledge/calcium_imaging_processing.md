# 图像预处理

原研究使用 Minian 1.2.1 处理单光子钙成像数据。处理流程包括背景荧光与传感器噪声预处理、运动校正和候选细胞体检测。原始成像帧、处理后的细胞空间轮廓和钙时间序列属于不同数据层级，平台中的活动摘要不能被描述为原始荧光图像。

# 细胞与活动提取

研究使用约束非负矩阵分解，将视频分解为细胞空间轮廓和各细胞的钙活动时间序列，再通过去卷积估计钙瞬变时刻。去卷积结果是基于模型的活动估计，不等同于同步电生理记录到的动作电位。ROI 数量、活动比例和峰值都依赖预处理参数及细胞筛选规则。

# 跨会话细胞配准

同一动物跨会话的细胞使用 CellReg 进行配准，依据空间位置和附近细胞轮廓相关性判断不同会话中是否为同一细胞。配准结果具有不确定性。只有在存在有效配准标识时，才能讨论某个细胞跨天保持、重现或共同参与；不能仅凭两个会话中相同的 ROI 序号认定为同一细胞。

# 与行为及睡眠对齐

原研究根据计算机毫秒时间戳，为每个行为帧寻找最近的钙成像帧，并限制钙帧重复使用。涉及 EEG/EMG 的实验中，钙活动按同一时刻对应到 6 秒睡眠状态窗；遥测缺失时标记为无状态并排除。项目应保存对齐依据和缺失范围，避免仅按数组位置拼接不同信号。

# 复核建议

分析钙活动时应优先描述可复核指标，例如有效 ROI 数、平均或中位活动、活跃细胞比例、事件附近窗口变化和数据缺失率。跨阶段比较应确认使用相同处理口径；若处理参数、帧率或配准质量未知，应降低证据充分程度并建议查看原始 NWB 元数据。
