# 研究设计

DANDI 000718 记录了小鼠跨日记忆关联研究。研究包含中性环境暴露、恐惧条件化、条件化后的离线记录、随后多日的记忆回忆，以及部分跨周记录。不同会话代表不同采集时段，不能把各会话中相同的相对秒数理解为同一真实时刻。

恐惧条件化会话通常先经历基线期，再给予足底电击，之后继续记录行为。回忆会话不应被解释为新的电击会话，其重点是观察动物回到不同环境后是否出现冻结等记忆表达。离线会话用于观察学习后休息、清醒或睡眠期间的神经活动。

# 数据模态

条件化和回忆相关会话可包含行为视频、冻结行为、运动信息、单光子钙成像、细胞分割结果和钙活动时间序列。离线会话可包含钙活动、脑电、肌电、活动信号和睡眠或清醒状态标签。并非每场会话都有全部模态，解释时必须以当前会话实际载入的数据为准。

# 时间基准

NWB 文件中的 session_start_time 和 timestamps_reference_time 是会话时间参考。会话内时间为零表示该会话的真实开始时刻。跨会话比较必须先把相对时间转换为真实采集时间；如果两个采集区间不重叠，只能比较阶段顺序、真实间隔和会话级汇总，不能声称存在逐秒同步关系。

# 解释注意事项

冻结行为可作为恐惧相关行为表现之一，但需要结合实验阶段和环境条件解释。钙活动、脑电、肌电和运动是不同层面的观测，某一模态的变化不能单独证明因果机制。缺少视频、行为标签或生理信号时，应明确指出证据不完整并建议人工复核。
