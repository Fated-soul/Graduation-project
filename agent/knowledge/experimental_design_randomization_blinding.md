# 实验单位与比较组

设计实验时应先明确实验单位、处理因素、比较组和主要结局。笼位、批次或同一动物的重复测量可能造成数据相关性，不能简单把每条时间窗记录都当作独立样本。平台中的大量时序数据不会自动增加独立实验动物数量。

# 随机化

随机化用于减少系统性分配偏差。应记录随机化发生在哪个层级、采用何种分配方法以及是否进行分层。若动物、笼位或会话并非随机分配，Agent 应把组间差异描述为观察性结果，不应暗示已经排除了选择偏差。

# 盲法

盲法可应用于处理实施、行为评分、ROI 筛选和统计分析等阶段。自动分析并不天然等于盲法，因为参数选择和异常排除仍可能受组别信息影响。系统应保存人工复核者、复核时间和修改理由，便于判断结果是否在不知组别的条件下获得。

# 样本量与重复测量

样本量应围绕主要结局、预期效应、变异和统计设计确定。单只动物的多会话数据适合描述个体内变化，但不能替代生物学重复。平台可以提供数据完整性和效应描述，不应仅凭时间点数量宣称统计把握度充足。

# Agent 使用边界

Agent 在评价造模效果前应检查比较组、动物数量、实验单位、随机化和盲法信息。缺少这些信息时，可以总结当前动物的多模态表现，但应把群体因果结论和推广性判断列为待验证内容。
