# 处理链路

钙成像常见处理链路包括运动校正、空间成分与时间轨迹提取、背景分离、质量筛选和活动反卷积。每一步都会影响最终 ROI 数量和活动曲线，因此平台中的 ROI 统计属于处理结果，不等同于直接观测到的神经元数量。

# 运动与背景

头戴显微或自由活动记录容易出现整体位移、局部形变和背景荧光变化。运动校正后仍应检查视野边缘、快速运动区间和残余漂移。若某个活动峰只在明显位移时出现，或多个 ROI 同时出现高度一致的异常变化，应优先排查运动和背景伪迹。

# ROI 接受标准

空间形状、信噪比、与原始图像的相关程度以及时间轨迹特征可共同用于筛选候选成分。阈值与初始化方式会改变召回率和误检率，不应把单一阈值视为适用于所有会话。自动接受或拒绝的 ROI 应保留质量指标，方便人工复核和版本比较。

# 跨会话注册

跨日追踪同一细胞需要先对齐视野，再根据空间足迹等信息完成成分注册。位置接近并不能单独证明是同一细胞，视野形变和细胞重叠都会带来不确定性。没有可靠注册结果时，平台只能比较群体统计，不能把两个会话中的同序号 ROI 当作同一细胞。

# Agent 使用边界

Agent 可以描述群体平均活动、活动 ROI 比例、峰值变化及其与行为事件的时间关系。若缺少运动校正质量、ROI 筛选指标或跨会话注册，结论应停留在“钙信号活动模式”层面，不能直接推断放电数量或单细胞记忆编码机制。
