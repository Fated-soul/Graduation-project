# 条件化基本关系

恐惧条件化将原本中性的线索或环境与厌恶性非条件刺激建立联系，足底电击通常作为非条件刺激。形成关联后，动物再次接触相应线索或环境时可能出现冻结等条件反应。冻结是可量化的行为指标，但它不是对“恐惧程度”的直接测量，也不能单独证明某个神经机制。

# 阶段化复核

训练会话应区分刺激前基线、线索期、刺激附近和刺激后阶段。基线用于判断动物是否在刺激前已经存在较高静止水平；训练过程中的冻结变化用于描述行为获得过程；回忆会话通常不再施加足底电击，重点是观察动物在原环境、相关环境或新异环境中的反应。不同阶段的冻结不能脱离会话类型直接比较。

# 环境与对照

情境线索包括装置形状、地面、气味、清洁方式和运输条件。回忆测试改变环境时，观察到的差异可能与情境辨别或泛化有关。可靠判断需要结合刺激组与无刺激组、训练环境与新异环境、刺激前与刺激后等对照；单只动物的单个冻结片段只适合形成待复核线索。

# 视频复核

自动冻结标签应与行为视频、运动信号和时间戳共同复核。装置遮挡、跟踪丢失、睡眠或普通静止都可能表现为低运动。实验人员应检查刺激时间附近的视频，确认动物反应和标签边界，并把修订理由写入人工注释，而不是直接覆盖原始标签。

# Agent 输出边界

Agent 可以报告冻结比例、持续时间、与电击的时间关系及跨环境差异，并指出还需要哪些对照。没有基线、视频或环境信息时，应使用“观察到静止或冻结标签增加”等描述，不应直接给出“造模成功”或“记忆已经形成”的确定结论。
