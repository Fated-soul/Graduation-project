# 研究设计

ARRIVE 2.0 要求说明实验组、对照组和实验单位。平台中的一只动物、一个笼位或一次会话不一定等同于独立实验单位，必须根据实际设计确定。Agent 不应把大量时间窗或 ROI 当作大量独立动物，也不能用单只动物的重复测量替代组水平证据。

# 样本量与纳入排除

报告应给出各组实验单位数量、样本量决定依据、预先设定的纳入排除标准，以及每项分析实际使用的数量。数据掉帧、视频不可用、ROI 质量不足和会话缺失都应形成可追溯记录。排除数据时需要保留原因，不能只展示筛选后的结果。

# 偏倚控制

随机分组、实验顺序随机化、分析盲法和预设结局指标有助于减少偏倚。如果公开数据没有提供这些信息，平台应显示为“未记录”或“无法由当前数据确认”，而不是默认已经执行。自动分析结果也应允许人工复核并保留修改痕迹。

# 统计与结果表达

结果应区分描述性统计、组间推断和机制解释。除了平均值，还应报告适当的变异信息、实际样本量和数据缺失情况；适用时给出效应量及置信区间。多个时间窗、多个 ROI 和多次比较会增加偶然差异风险，Agent 应提醒使用与研究设计匹配的统计方法。

# 动物与实验过程

可复现报告需要说明物种、品系、性别、年龄或发育阶段，以及实验过程做了什么、何时做、频率、地点和理由。当前 DANDI 数据可以提供其中一部分信息，但不能自动补全伦理审批、饲养条件或未公开操作。生成报告时应列出已知信息和待补充信息。

# 平台中的使用方式

ARRIVE 条目用于检查证据链和报告完整性，不用于给单只动物计算“合格分数”。Agent 在给出造模评估时，应明确当前结论属于单会话观察、单动物纵向趋势还是组水平比较，并把缺失的设计信息列入限制条件。
