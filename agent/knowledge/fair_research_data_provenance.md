# 可发现与可访问

研究数据应具有稳定标识和足够元数据，使人和程序能够找到对应动物、会话、文件和处理结果。可访问不意味着必须公开全部数据，而是访问方式和权限条件需要明确。平台同步公开数据时应同时保存数据集标识、版本和资产标识。

# 可互操作

不同来源的数据需要使用明确格式、单位和共同语义才能组合。NWB 提供神经生理数据结构，但具体字段仍需结合实验说明解释。数据库中的中文展示名称不应替代原始类型、单位和时间参考，二者应保持可追溯映射。

# 可复用

复用需要了解许可、实验背景、处理方法、质量状态和来源。只保存派生均值而丢失原始文件与处理参数，会削弱后续复核能力。平台应区分原始资产、解析结果、人工注释和 Agent 结论，不让后生成内容覆盖前序证据。

# 版本与来源

公开数据集可能更新，固定版本能够保证分析对象可重复定位。知识文档和模型配置也应保留版本信息。Agent 引用资料时需要返回标题和来源链接，使使用者能够核对资料，而不是只展示无法追溯的摘要。

# Agent 使用边界

FAIR 描述数据管理质量，不直接保证实验结论正确。Agent 可以利用完善的元数据提高检索和溯源能力，但仍需根据实验设计、信号质量和证据完整性判断结论强度。
