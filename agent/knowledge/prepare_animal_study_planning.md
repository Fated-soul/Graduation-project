# 研究前规划

PREPARE 强调在研究开始前同时考虑科学目标、伦理要求、动物福利、设施条件和人员协作。系统中的会话记录与分析结果只能反映已采集证据，不能替代实验开始前的方案论证和审批。

# 角色与沟通

研究人员、动物设施人员、兽医和技术人员需要提前明确职责、操作流程和异常处置方式。平台可记录实验负责人、数据复核者和处理状态，使后续发现问题时能够定位责任环节，但不应把未记录的操作视为已完成。

# 动物与设施条件

品系、性别、年龄、健康状态、饲养条件、运输、适应和昼夜节律都可能影响行为和生理结果。比较不同会话时，应优先检查这些背景是否一致；如果元数据缺失，应把潜在混杂列入结论限制。

# 操作与终点

刺激强度、操作顺序、麻醉镇痛、监测频率、人道终点和意外事件处理应在方案中预先规定。Agent 可以发现偏离计划的信号或缺失记录，但任何涉及动物处置的建议都必须由具备资质的研究人员确认。

# 数据管理

采集前应确定文件命名、时间同步、原始数据保存、质量检查和备份方式。会话结束后再补录元数据容易产生时间和条件误差，因此平台应把来源、版本和处理步骤作为证据链的一部分持续保存。
