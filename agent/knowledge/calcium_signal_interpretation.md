# 间接活动指标

GCaMP 荧光反映细胞内钙变化，是神经活动的间接指标。动作电位可引起荧光瞬变，但荧光幅度、上升和衰减还受到传感器动力学、表达水平、基线荧光和噪声影响。因此钙活动增加可用于支持“神经活动代理指标增强”，不能直接换算为精确放电频率。

# 非线性与检测率

指标验证研究表明，GCaMP 荧光与动作电位之间可能存在非线性关系，少量动作电位不一定都能被检测，而较强活动可能产生放大的荧光差异或接近饱和。不同试次之间的荧光波动既可能来自神经活动差异，也可能来自传感器响应和测量噪声。

# 时间分辨率

钙信号的变化速度慢于动作电位，临近事件的荧光峰可能整合了一个时间窗内的活动。Agent 应使用“刺激前后时间窗”“事件附近活动变化”等表述，避免把单个采样点解释为瞬时放电。比较时间关系时还要考虑成像帧率、去卷积方法和对齐误差。

# 合理比较范围

同一实验动物、相同处理流程和相近记录条件下的相对变化通常比跨动物绝对荧光值更容易解释。跨会话比较需要考虑 ROI 配准、基线归一化、运动伪迹和细胞筛选。缺少这些信息时，应报告趋势和数据完整性，不应声称某一细胞群被确定激活或抑制。
