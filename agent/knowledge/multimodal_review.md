# 基线适应

基线适应用于了解动物在未接受厌恶刺激时的行为和神经活动背景。分析应关注探索活动、基础冻结水平、运动变化和钙活动分布。基线数据可作为后续阶段的参照，但不同日期、环境或记录条件下的绝对信号值不宜直接等同。

# 恐惧条件化

恐惧条件化复核应先确认电击发生时间，再分别观察电击前、刺激附近和刺激后的冻结、运动和钙活动。时间上的共同出现只能说明同步观察或相关变化，不能单独证明刺激导致某个神经机制。视频与人工标注可用于验证自动行为标签。

# 记忆回忆

记忆回忆评估通常不包含新的足底电击，重点是动物在厌恶、中性或新异环境中的行为表达。冻结时间、冻结比例和环境差异应结合基线与条件化经历解释。若缺少环境类别或对照会话，应降低结论强度。

# 离线巩固

离线会话应在本场会话内部对齐睡眠状态、脑电、肌电、活动和钙信号。脑电和肌电有助于支持睡眠或清醒状态判断，运动信号可辅助识别静止。与条件化会话比较时，应使用真实采集时间表达先后与间隔，不得按两场会话各自的相同秒数建立虚假对应。

# 证据充分程度

证据充分程度应综合当前会话的数据完整性、人工复核情况、多模态之间是否相互支持，以及检索资料与问题的相关程度。该数值表示当前判断有多少可核对依据，不是生物学结论为真的概率，也不是模型自信程度。
