# 统一时间参考

NWB TimeSeries 的 timestamps 以秒为单位，相对于 NWBFile.timestamps_reference_time 所定义的实验主时钟。session_start_time 表示会话开始时间，timestamps_reference_time 表示时间序列零点；两者可能相同，也可能承担不同含义。解析时应保留时区并转换为可比较的绝对时间。

# 显式与规则采样时间

时间序列可以保存每个样本的显式 timestamps，也可以通过 starting_time 与 rate 表示规则采样。对齐程序应优先使用文件中实际提供的时间信息，不应根据样本序号猜测采样时刻。事件区间的开始与结束时间也必须落在同一会话时间参考下。

# 会话内对齐

只有共享同一主时钟或已知同步转换关系的模态，才能做逐时间点对齐。行为视频、刺激事件、钙活动、EEG 和 EMG 的采样率可以不同，对齐时应保存最近邻、窗口聚合或重采样规则，并显示允许误差。缺失范围需要保留为空白。

# 跨会话对齐

不同 NWB 文件中的相对时间零点彼此独立。跨会话比较必须先计算“时间参考点 + 会话内秒数”得到真实采集时间。若 FC 与 Offline 会话不重叠，只能比较先后顺序、间隔和会话级指标，不能把各自第 100 秒叠加为同一时刻。

# Agent 复核规则

当用户询问某两个现象是否同时发生时，Agent 应先检查它们是否属于同一会话、是否存在绝对时间、采集区间是否重叠以及对齐误差是否可接受。只要其中一项不满足，就应改为描述阶段关系或时间间隔，并指出无法进行逐秒同步判断。
