# 姿态追踪与行为结论

无标记姿态估计可以从视频中定位实验动物的身体关键点，并据此计算位置、速度、姿态和活动轨迹。关键点坐标是算法输出，不等同于冻结、探索或回避等行为结论。平台应把坐标、运动特征和行为标签分层保存，避免把一次识别结果直接解释成生物学状态。

# 置信程度与异常帧

关键点通常伴随逐帧置信程度。低置信帧可能来自遮挡、光照变化、动物贴近边缘、快速运动或训练数据覆盖不足。分析连续行为区间时，应先标记低置信范围，再决定插值、排除或人工复核；不能用长距离插值掩盖连续跟踪失败。

# 视频抽查策略

人工复核应优先覆盖刺激前后、行为标签转变处、轨迹突变处和置信程度持续偏低的区间。抽查时同时查看原视频、关键点覆盖图和派生速度，判断低运动究竟来自冻结、普通静止、睡眠、遮挡还是跟踪丢失。修订结果应作为独立注释保存，并保留原始自动识别记录。

# 跨会话比较

不同会话的视频分辨率、镜头位置、视野范围和照明条件可能不同。跨日比较速度或活动范围前，需要确认像素到空间尺度的换算方式一致，并记录模型版本和关键点定义。若条件不一致，应优先比较会话内标准化指标，而不是直接比较原始像素位移。

# Agent 使用边界

Agent 可以根据追踪覆盖率、低置信比例、活动轨迹和人工注释判断视频证据是否可用，但不应把姿态模型置信程度表述为行为结论的概率。缺少原视频或异常区间未复核时，应明确说明行为判断仍需人工确认。
